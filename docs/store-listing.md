# itch.io 스토어 등록 초안

## 제목

Hackspot — 사라진 11분

## 짧은 설명

메일, 가상 웹과 터미널의 기록을 연결해 사라진 11분의 진실을 추적하는 한국어 사이버 조사 추리 게임

## 상세 설명

바다를 조사하던 관측소의 누락된 기록을 추적하세요.

실제 해킹과 달리 모든 작업은 이 브라우저 안의 안전한 가상 환경에서 이루어집니다. 공개 보고서와 시민 교대 기록을 비교하고, 터미널 명령으로 가상 서버에 접속해 세 증거를 대조한 뒤 판단을 제출하세요.

### 특징

- 약 15~20분 분량의 단일 사건
- 메일, 브라우저, 터미널, 파일, 메모를 사용하는 조사형 인터페이스
- 가상 셸과 네트워크 명령 실습
- 두 가지 결말과 저장 기반 재도전
- 데스크톱과 작은 화면 대응
- 별도 계정이나 서버 없이 브라우저에서 진행

### 권장 가격

- 기본권장: 미국 달러 4.00
- Pay what you want 또는 최소 달러 3.00은 출시 직후 전환을 판단

### 시스템 요구사항

- Chromium 계열 또는 WebKit 계열 최신 데스크톱 브라우저 권장
- 현재 버전은 마우스와 키보드 환경에 최적화
- 모던 브라우저의 `localStorage` 사용 필요

### 저장 안내

진행과 메모는 브라우저에 저장됩니다. 브라우저 데이터를 삭제하거나 공개 주소를 변경하면 기존 진행을 찾지 못할 수 있습니다.
