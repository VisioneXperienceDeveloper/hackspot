## 프로젝트 맥락과 이번 범위

「Hackspot — 사라진 11분」은 React + TypeScript + Vite로 만든 한국어 단일 사건 조사 게임이다. 가상 사이트 3곳, 서버 2곳, 증거 3개, 명령 10개와 두 결말을 제공한다. 게임 상태와 순수 도메인 로직은 UI에서 분리되어 있고 localStorage 단일 슬롯으로 저장한다. 실제 외부 접속·계정·전송 서비스는 없다.

이번 작업은 10월 29일 분석에서 발견한 현재 제품의 결함과 개발/검증 공백을 해결하고 DESIGN.md의 단일 사건 구현을 완성하는 범위다. 공개 배포, 실물 기기·신규 사용자 플레이테스트, 두 번째 사건, 계정/동기화/여러 저장 슬롯은 별도 작업이다. 아래 미래 단계는 이번 수정의 미완료 버그를 뜻하지 않는다.

## 2026-11-05 — 데스크톱·메모 파일 UI 갱신

Status: Done
Updated: 2026-11-05 17:13 Australia/Sydney

- 상단 로고를 Hackspot으로 변경하고 오른쪽 끝 점 세 개 버튼에서 진행 기록·힌트 패널을 연다. 기본적으로 숨기며 둥근 반투명 패널로 앱 창 위에 표시한다. 바깥 클릭·포커스 이탈·X·Escape로 닫고 기존 고정 패널 예약 공간을 없앴다.
- 증거 보관함을 폴더로 바꾸고 메모장을 별도 앱으로 분리했다. 메모장의 본문 제목·설명·placeholder를 없애고 빈 편집 영역과 새 메모·저장하기를 제공한다.
- 다른 이름으로 저장 창에 저장 위치 사이드바·경로·폴더 및 파일 목록·새 폴더·파일 형식을 제공한다. 같은 경로의 다른 파일은 덮어쓰기를 확인한다. 초안과 저장 파일은 별도로 유지한다.
- 폴더는 Finder 형태로 새 폴더·파일/폴더 이동·이름 변경·아이콘/목록 보기·현재 폴더 검색을 지원한다. 폴더 이동과 이름 변경은 하위 경로를 함께 바꾼다. 텍스트·로그는 메모장, EML은 메일, CSV는 액셀에서 직접 연다. 액셀은 셀 선택·셀 주소와 값·방향키 이동을 지원한다.
- v1 저장에 선택적 noteFiles·folders·fileLocations를 추가했다. 이전 메모 초안을 보존하며 빈 폴더와 사용자 파일 경로를 저장한다. 파일별 10,000자·최대 100개, 최대 폴더 200개, 이름·중복 경로·참조 관계를 검증한다.
- 작업 표시줄 왼쪽을 검색 아이콘으로 바꾸고 설치된 6개 앱·수집한 증거·대조표·저장한 메모 파일을 이름·경로·본문으로 검색해 연다. 미확보 파일은 노출하지 않는다. ↑↓·Enter·Escape를 지원한다.
- 작업 표시줄은 실행 중인 앱만 보여준다. 최소화는 인스턴스와 초안을 유지한다. X는 인스턴스를 해제하고 목록에서 제거하며 재실행은 초기 화면으로 연다. 터미널 세션·출력·명령 기록과 미저장 메모 초안은 X 종료 시 초기화한다. 수집한 증거와 저장한 메모 파일은 유지한다. 우클릭 종료 메뉴는 최종 요청에 따라 제공하지 않는다.
- 오른쪽 아래 진행 화살표를 제거하고 현재 로컬 시각을 표시한다. 시계만 초 단위로 갱신하며 탭 복귀 시 다시 동기화한다.
- 영역: App, Window, Files, Notes, FileViewers, DesktopSearch, Clock, appInfo, windowGeometry, noteFiles, desktopFiles, storage, styles, game E2E, hosting 검사.
- 검증: 로컬 127.0.0.1:4173에서 Ego Lite로 716×902·812×827·851×827·390×664·320×568 배치, 진행 패널 토글·바깥 클릭·Escape·포커스 복귀, 빈 메모장·검색·현재 시각을 확인했다. Browser 플러그인은 없으며 기존 Playwright 검사도 사용한다.
- `npm run check`: lint, 포맷, 단위 테스트 42개, TypeScript, 프로덕션 빌드 통과. `npm run test:e2e`: Chromium 데스크톱·모바일 에뮬레이션·WebKit에서 38개 통과, 모바일 데스크톱 창 드래그 1개 적용 제외. 두 결말, 메모 저장과 Finder 파일 조작, CSV의 액셀 연결·셀 선택과 방향키를 검증했다. 마지막 폴더 경로·저장 창 보완 후 관련 6개 흐름을 다시 확인했다. `npm run test:hosting`: 최종 빌드의 `/` 및 `/nested/`에서 자산 로딩과 메모 파일·초안 복구 통과.
- 남은 범위: 기존 Phase 2의 실제 OS IME·실물 키보드·신규 사용자 플레이테스트와 Phase 3의 공개 배포는 별도다.

## 이전 안정화 검증 결과 (2026-10-31)

- `npm ci`: 성공. Node 22.22.1 환경. 지원 최소 Node 22.13.
- `npm run check`: ESLint, Prettier, **단위 테스트 34개**, TypeScript, Vite 프로덕션 빌드 통과.
- `npm run test:e2e`: **29개 통과, 1개 적용 제외**. 제외 항목은 단일 창 모바일 레이아웃에서 제공하지 않는 데스크톱 드래그 크기 조절이다. 모바일 앱 전환·단일 창·작은 화면 경계는 별도 테스트로 통과했다.
- 환경: 127.0.0.1:4173 프로덕션 미리보기. Chromium 1440×900, 모바일 에뮬레이션 390×664, WebKit 1280×800. 추가 viewport 320×568, 768×1024, 900×500.
- 실제 조작 흐름: 새 게임 → 사이트 3곳 → 인증 실패/복구 → 열람/증거 → 중간 새로고침 → 메모/증거 복구 → 대조 → 잘못된 판단 → 수정 → 두 결말 → 새로고침 후 결말 복구.
- 페이지 제목·의미 있는 최초 화면·프레임워크 오류 화면 부재·스크린샷·콘솔 warning/error·pageerror·실패한 요청을 확인했다. 관련 앱 오류는 없었다. 테스트 실행기의 NO_COLOR/FORCE_COLOR 경고는 페이지 오류가 아니다.
- Browser 플러그인/스킬이 없어 Playwright로 검증했다. 사용자 브라우저 대신 격리 컨텍스트를 사용했다.
- `npm run test:hosting`: 임시 정적 서버의 `/`, `/nested/` 모두 배경/JS/CSS 로딩 및 메모 즉시 새로고침 복구 성공.
- 저장 벤치마크: 10,000자 메모 + 100개 명령 기록 + 160개 터미널 출력, 직렬화 후 **467,654자**. JSON 직렬화+localStorage 쓰기 30회 중 p95 **4.0ms / 4.3ms**. 이 기기의 합성 부하이며 모바일 실기기 성능 보장은 아니다.
- 산출물: JS 291.80 kB(gzip 90.77), CSS 22.44 kB(gzip 5.78). 배경 PNG 약 1.9MB. 배경 이미지는 유지했다.
- 실제 OS 한글 입력기, 모바일 실물 키보드, 강제 프로세스 종료, 신규 사용자 15~20분 목표, 공개 URL, 원격 GitHub Actions 실행은 검증하지 않았다.
